- **已核实**：下列固定提交中确实存在的代码、公式、依赖声明和许可文本。
- **合理判断**：学习成本、与本项目口径的差异，以及复用代价。
- **尚未验证**：没有安装或运行任何候选项目，没有执行其测试，没有在 Windows 11／Python 3.13 上实际验证兼容性。没有进行完整安全审计或漏洞扫描。

最近提交日期按北京时间列出；它不等于最近发行日期，也不能单独证明活跃维护或代码成熟。依赖清单中的版本下限不能证明 Python 3.13 可运行，仍需之后核实兼容版本并实测。

## 3. 本项目的选择

本轮**不复制代码、不引入任何候选作为基础框架、不安装依赖**。原因是：

1. 许可完整且可考虑复用的 A 候选，不符合一单多明细和部分退款的核心口径，移植后仍要重做这些计算与测试。
2. B 许可文本不完整，C、D 没有找到明确许可；不能通过改写表面语法或移除版权说明来绕过授权问题。
3. 当前规模仅 80 行，Python 标准库已经可以完成下一阶段的 CSV 读取、金额校验和基础聚合，不需要先引入 Web 界面、数据库或 AI API。
4. 对初学者而言，先明确数据粒度和可对账的指标，比部署一个功能繁多但口径不匹配的看板更容易掌握和验收。

采用的只是通用设计思路：先校验数据，再按订单和商品分别聚合；分开编写读取、计算和输出；为退款和边界情况准备明确的验收答案。没有把候选仓库的代码、数据或图片复制进本项目。

下一阶段若需要复用具体代码，须再次核实该文件及依赖的许可、保留必要版权与许可声明，并在隔离环境测试。未来若选择 pandas 等通用库，也需先确认版本对 Python 3.13 的支持，再经授权安装。
